# 461: SPEC conformance, wipe and loop-devices engineering.md

## Objective

Hold every requirement of `docs/wipe/engineering.md` and
`docs/loop-devices/engineering.md` to the code: name the code that meets it
and a unit test that fails if it breaks. Where a requirement has no test, add
one beside the existing ones; where the code does not meet it, fix it with a
test. Tests use temp files and the packages' own seams only (no root, no real
block or loop device).

## Slices

1. `docs/wipe/engineering.md`, section by section: exported surface,
   invariants, configuration, error semantics, persistence. Tests added in
   `pkg/wipe` (and `pkg/luks2` for the header-only wipe) for each requirement
   found without one, starting with lock contention on `Sanitize`
   (`ErrLockContended`). Commit: `test(wipe): ...`.
2. `docs/loop-devices/engineering.md`, section by section. Tests added in
   `pkg/loop` (fakes only) for each requirement found without one. Commit:
   `test(loop): ...`.

Each doc gets an accuracy fix only where it misdescribes the code.

## Out of scope

- The CLI rows (`cli.md`), already audited.
- Integration tiers that need a real block or loop device or root.
- Any fix that needs a design or API change: listed in the lane report, not
  made.
- `docs/SPEC.md`, `ROADMAP.md`, CI workflows.
