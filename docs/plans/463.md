# 463: SPEC conformance, public releasability

## Objective

Hold each requirement of `docs/release/public-releasability.md` and of the
release row of `docs/SPEC.md` (the published tree carries no fleet value and
no internal-only file) to the code that meets it and a test that fails if it
breaks. Add the tests that are missing and fix the code or the page where they
disagree. The package documentation of `test/internal/labstrings` wins over
the page.

## Slices

1. Conformance table (in the pull request): requirement, code, test.
2. `make releasability` runs the gate over the checkout and fails when the
   gate fails: `test/makefile/releasability_test.go`,
   `TestReleasabilityRunsTheGateOverTheCheckout`.
3. The page's strip-at-publish table is `DefaultStripAtPublish`, pattern for
   pattern: `test/tools/releasability-gate/export_test.go`,
   `TestThisPage_ListsEveryStripAtPublishPattern`. The page named a review
   workflow the list does not carry; the page is corrected.

## Out of scope

- The list of published workflows (another branch changes it).
- `.github/`, `.gitattributes`, `docs/SPEC.md`, `ROADMAP.md`.
- `TestVerifyFailsOnAModuleCacheWithoutSources` (fixed elsewhere).
- Design changes; they are listed in the pull request instead.
