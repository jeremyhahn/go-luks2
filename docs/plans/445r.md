# 445r: recovery-keys engineering.md conformance

## Objective

Map each requirement of `docs/recovery-keys/engineering.md` (Exported
surface, Invariants, Generated credentials, Test strategy, Observability) to
the code in `pkg/luks2/recovery.go` and a test that fails if it breaks. Add the
missing tests; fix the code (with a test) where it does not meet the document;
correct the document where it is inaccurate. Error semantics, Persistence and
the format-table renderings are audited elsewhere and are skipped here.

## Slices

1. Plan (this file).
2. `pkg/luks2/recoveryengconformance_test.go`: unit tests (t.TempDir images,
   the package's fakes only) for each requirement the audit marks missing:

     reader is `crypto/rand.Reader`; no option supplies another);
   - the credential, and what `ParseRecoveryKey` returns, are held in
     go-enclave locked memory;

     below it refused) and no exported option reaching the exemption;
   - the remaining Invariants and Generated-credentials rows as found.
3. Accuracy fixes to `docs/recovery-keys/engineering.md`, if any.
