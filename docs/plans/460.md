# 460: SPEC conformance, keyslots and tokens engineering.md

## Objective

Audit every requirement in `docs/keyslots/engineering.md` and
`docs/tokens/engineering.md` against the code. For each requirement name the
implementing code (file:func) and a unit test that fails if the requirement
breaks. Where no such test exists, add one beside the existing tests; where
the code does not meet the requirement, fix it with a test. Fixes that need a
design or API change are listed, not made.

## Slices

1. Plan (this file).
2. `docs/keyslots/engineering.md`, section by section: tests for the
   requirements without one, under `pkg/luks2/*_test.go`; doc accuracy fixes
   where the doc and the code disagree and the code is right.
3. `docs/tokens/engineering.md`, section by section: the same, for tokens.

## Out of scope

- The CLI rows (`cli.md`), already audited.
- Design or API changes; they are reported for a later row.
- `docs/SPEC.md`, `ROADMAP.md`, CI configuration.
- The module-cache verification test another row fixes.
