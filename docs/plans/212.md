# 212: unit and race tests under their time budgets

## pkg/luks2

### Objective

`make test-unit` runs `go test -race ./pkg/luks2` against a 240s budget
(Makefile UNIT_TEST_TARGET). Bring the package under it with every test,
assertion and gate unchanged, production KDF defaults unchanged.

### Measurement (race, before)

- Package 231s on an 80-CPU container with an 8 MiB memlock limit (seven
  locked-memory slots for `parallel(t)`); CI runners report more.
- 445 serial top-level tests take 131s; 81 of them (>= 0.5s each) take 107s.
- The parallel tests (225) overlap into roughly 100s; their slowest are the
  ChangeKeyslot tests that raise a slot to the production PBKDF2 floor (a
  hard-coded floor in the preserve path, with no test-only knob).
- Top-level parallel tests only run after every serial test has finished, so
  a serial test that swaps a package global never overlaps a parallel one.

### Slices

1. Mark the heavy serial tests parallel with `defer parallel(t)()` (the
   locked-memory semaphore), after checking each for package-level state.
   Kept serial: tests that swap `custody` or `sysDevBlockRoot`, and tests
   whose subject is wall-clock calibration. Test: the package passes with
   and without -race; re-measure.
   TestMigrateToFIPSResumedAfterACrashKeepsAWayIn's middle level is made
   parallel too: a sequential level between a slot-holding parent and
   slot-taking subtests is the shape parallel(t) documents as a deadlock.
2. Move fixture-only Format setups onto the formattedImage cache:
   argon2VolumeImage (Argon2id at 64 MiB, pure Go and so slowest under
   -race) and the 700k-round PBKDF2 fixture three ChangeKeyslot tests
   formatted each. A test needing two distinct volumes asks for two keys.
   Re-measure.

Not changed: Format-subject tests (metadatasize_test.go) and the
ChangeKeyslot preserve path, which raises a slot to the production floor by
design; those derives are the subject.

### Out of scope

- Production code, the preserve-path floor, Makefile budgets, -timeout,
  .github/, docs/SPEC.md, ROADMAP.md.
- Any skip, testing.Short gating or weakened assertion.

## test/makefile

### Objective

`go test -race ./test/makefile` hit the 10-minute go test timeout in CI's
Race job. Bring the package well under the ceiling (target: under 4 minutes
with -race on a 4-CPU runner) without weakening any test or gate, without a
raised -timeout, and without editing the Makefile or CI workflows.

### Method

Measure first: `go test -race ./test/makefile -count=1 -v`, list the 15
slowest tests, fix one cause per commit, re-measure after each.

### Slices, in order (each confirmed by the timing table first)

1. Seam-var scan: one shared source importer and file set for every
   `seamVarsIn` call, so the standard library and each dependency are
   type-checked once per test binary, not once per package directory.
   Covered by the existing seam tests (`TestNoNewSeamVars`,
   `TestSeamAllowlistNamesOnlyRealSeams`,
   `TestSeamVarsInReportsAPackageThatDoesNotTypeCheck`).
2. Per-package make dry-runs: run independent read-only subtests
   (`make -n`, probes) in parallel where the helpers are race-safe.
3. Cache `go list ./...` results in a `sync.Once`.
4. Nested go test runs (coverage report, test-pkg): share the build cache;
   only where the timing table shows them among the slowest.

### Out of scope

- The Makefile, `.github/`, docs/SPEC.md, ROADMAP.md.
- `TestVerifyFailsOnAModuleCacheWithoutSources` and `modFilesOnly`
  (another lane).
- Skip guards, short-mode gating, raised timeouts, weaker assertions.
