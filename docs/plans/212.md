# 212: pkg/luks2 unit tests under their time budget

## Objective

`make test-unit` runs `go test -race ./pkg/luks2` against a 240s budget
(Makefile UNIT_TEST_TARGET). Bring the package under it with every test,
assertion and gate unchanged, production KDF defaults unchanged.

## Measurement (race, before)

- Package 231s on an 80-CPU container with an 8 MiB memlock limit (seven
  locked-memory slots for `parallel(t)`); CI runners report more.
- 445 serial top-level tests take 131s; 81 of them (>= 0.5s each) take 107s.
- The parallel tests (225) overlap into roughly 100s; their slowest are the
  ChangeKeyslot tests that raise a slot to the production PBKDF2 floor (a
  hard-coded floor in the preserve path, with no test-only knob).
- Top-level parallel tests only run after every serial test has finished, so
  a serial test that swaps a package global never overlaps a parallel one.

## Slices

1. Mark the heavy serial tests parallel with `defer parallel(t)()` (the
   locked-memory semaphore), after checking each for package-level state.
   Kept serial: tests that swap `custody` or `sysDevBlockRoot`, and tests
   whose subject is wall-clock calibration. Test: the package passes with
   and without -race; re-measure.
2. If still over: move fixture-only Format setups (per-test formatForTest,
   argon2VolumeImage) onto the formattedImage cache. Re-measure.

## Out of scope

- Production code, the preserve-path floor, Makefile budgets, -timeout,
  .github/, docs/SPEC.md, ROADMAP.md.
- Any skip, testing.Short gating or weakened assertion.
