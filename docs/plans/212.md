# Plan: test/makefile under the race timeout

## Objective

`go test -race ./test/makefile` hit the 10-minute go test timeout in CI's
Race job. Bring the package well under the ceiling (target: under 4 minutes
with -race on a 4-CPU runner) without weakening any test or gate, without a
raised -timeout, and without editing the Makefile or CI workflows.

## Method

Measure first: `go test -race ./test/makefile -count=1 -v`, list the 15
slowest tests, fix one cause per commit, re-measure after each.

## Slices, in order (each confirmed by the timing table first)

1. Seam-var scan: one shared source importer and file set for every
   `seamVarsIn` call, so the standard library and each dependency are
   type-checked once per test binary, not once per package directory.
   Covered by the existing seam tests (`TestNoNewSeamVars`,
   `TestSeamAllowlistNamesOnlyRealSeams`,
   `TestSeamVarsInReportsAPackageThatDoesNotTypeCheck`).
2. Per-package make dry-runs: run independent read-only subtests
   (`make -n`, probes) in parallel where the helpers are race-safe.
3. Cache `go list ./...` results in a `sync.Once`.
4. Nested go test runs (coverage report, test-pkg): share the build cache;
   only where the timing table shows them among the slowest.

## Out of scope

- The Makefile, `.github/`, docs/SPEC.md, ROADMAP.md.
- `TestVerifyFailsOnAModuleCacheWithoutSources` and `modFilesOnly`
  (another lane).
- Skip guards, short-mode gating, raised timeouts, weaker assertions.
