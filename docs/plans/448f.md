# 448f: FIPS SPEC conformance, engineering.md

## Objective

Map every requirement of `docs/fips/engineering.md` to the code that meets
it and to a test that would fail if it broke. Where no test proves a
requirement, add one; where the code does not meet it, fix it with a test.

## Slices

1. Exported surface: the `MigrationStage()` fold of every `Stage` string,
   `DefaultKDFType`/`DefaultKDFSpec`, `ChangeKeyslot` keeping the KDF on a
   zero `KDF`, `(KDFParams).Validate()` refusing non-approved KDFs.
2. Invariants and Approved KDFs: Argon2 and SHA-1 keyslots refused in FIPS
   mode, SHA-1 never written, the FIPS default calibrated to the SHA-512
   floor, Argon2 cost with no type giving `argon2id`.
3. Error semantics and Edge cases: `FIPSImportRequiredError` and
   `FIPSMigrationError` unwrap chains, short salt/output treated as
   non-approved with `NonApprovedKDF.Reason` naming the parameter.
4. Persistence, Test strategy, Observability: the named interruption and
   import tests exist; no logging.

Every new test goes in `pkg/luks2/fipsengconformance_test.go` (t.TempDir
files and the package's fakes only, no root, no real device).

## Out of scope

- `docs/fips/api.md` and the `internal/fips` mode tests (the open draft for
  the same issue owns them).
- The CLI rows (`cli.md`), already audited.
- Any change to FIPS behavior beyond a fix with a test; design or API
  changes are listed in the report, not made.
