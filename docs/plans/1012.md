# 1012: adopt the handbook code-review.yml template v5.12.5 unchanged

## Objective

Owner ruling 1012: `.github/workflows/code-review.yml` is the handbook
template v5.12.5 byte for byte (commit a3a612a), with no local edits. The
workflow tests accept exactly the template's form and nothing wider.

## Slices

1. Workflow (coordinator, a3a612a): template v5.12.5 verbatim.
2. Runs-on rule (this lane): `runsOnLabel` accepts the template's exact
   routing expression for the scope and gate jobs,
   `${{ github.server_url == 'https://github.com' && 'ubuntu-latest' || 'bigdisk' }}`,
   as ubuntu-latest. Table cases in `TestRunsOnViolation`: the exact string
   (bare and with a comment) passes; swapped labels, another label, other
   spacing, the quoted form and any other expression still fail.

3. Review fixes (coordinator decision, ruling 109): v5.12.5 with the
   go-luks2 CUSTOMIZE review fixes of 0e8e52e re-applied on top, every
   v5.12.5 change kept (the lock waits in the job budget, the routing
   runs-on, the review result check), so the twelve tests below pass with
   no test edit.

## Why slice 3 (the P1 slice 2 found)

The unchanged template drops go-luks2 security customizations that
`test/ci/workflows/codereview_test.go` protects. Eleven tests fail on the
template and pass on the previous workflow (0e8e52e):

- TestNoReviewPathsNeverExemptAWorkflow, TestScopeSkipNeverSuppressesAWorkflowReview:
  the template exempts `.github/` changes when the scope guard passes; its
  PROTECTED list covers only code-review, qwen-review, automerge, release,
  nightly, so ci.yml, signatures.yml, scans.yml and allowed_signers changes
  merge with no Codex review.
- TestGateRefusesARetargetedPullRequest, TestRearmRefusesARetargetedPullRequest:
  the gate and the rearm step do not read the live base against $BASE_REF.
- TestGateKeepsAStandingChangeRequest: the gate takes the latest verdict, so a
  later approval clears a standing REQUEST_CHANGES.
- TestGateGetAllPropagatesAFailedPage: get_all returns partial data on a
  failed or empty page (exit 0).
- TestGateRefusesAfterAFailedReviewAttempt, TestCarryRefusesAHeadWhoseLatestAttemptFailed:
  no latest-attempt read; an approval stands after a failed re-review.
- TestGateRefusesAFailedReviewJob: enforced another way (REVIEW_RESULT,
  v5.12.1); the test checks the old helper name.
- TestRunNameCarriesTheRequestKind, TestRearmChecksTheAutoMergeRequest,
  TestFreshOwnerResumeResetsAnExhaustedCount: run-name kind, enabledAt
  check, needs-coordinator relabel dropped.

## Out of scope

Deleting or weakening any test; other workflows.
